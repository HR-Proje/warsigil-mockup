# warsigil-mockup

Warsigil arayüz taslakları (HTML). Yayın: https://hr-proje.github.io/warsigil-mockup/

- Her ekran kendi klasöründe tek dosyadır: `<ekran-adi>/index.html` (844×390 yatay telefon ölçeği, dokunmatik).
- Kök `index.html` ekran listesidir; yeni ekran oraya bir satırla eklenir.
- Ortak görseller `assets/` altındadır; taslaklar `../assets/<dosya>.png` ile kullanır.
- Düzen referans ekrandan, görünüş Warsigil'in arayüz kurallarından gelir (oyun reposunda `Docs/GDD/Arayuz_Tasarimi.md`). Onaylanan taslak Unity'ye aktarılır.
